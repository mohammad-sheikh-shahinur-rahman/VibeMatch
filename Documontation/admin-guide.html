Admin Panel Operations & Monetization Guide

A complete walkthrough of daily administration tasks: user moderation, banning abusive members, setting diamond coin package prices, managing VIP tiers, and configuring payment gateways.

🔑 Accessing the Admin Dashboard

The administration panel is accessible directly from any web browser by navigating to the /admin path of your deployed domain (e.g., https://yourdomain.com/admin).

Log in with the master administrator credentials created during the initial setup wizard.

Figure 1: Admin Telemetry Dashboard displaying live online users, active calls, registered members, and revenue graphs.

👤 1. User Management & Moderation

Navigate to Admin > Users to inspect all registered accounts.

Figure 2: User Accounts Table with instant search, filter, and balance management.
  • Banning / Unbanning an Abusive User: Find the user in the table, click the red Ban action button (or toggle the status switch). The user's JWT token is instantly invalidated and active video calls are closed.
  • Adjusting Diamond Wallet Balance: Click the edit icon next to a user. Enter the new coin balance (e.g., to grant bonus diamonds for promotional support or refund a purchase) and click Save Changes.
  • Granting VIP Membership Status: In the user edit modal, toggle the VIP Status switch and pick an expiration date to grant premium matchmaking privileges.

🛡️ 2. Reviewing Abuse Reports

Navigate to Admin > Reports to review flagged members reported during live video chats.

  • Reports display the Reporter ID, Reported User, Reason (e.g., nudity, harassment, spam), and exact timestamp.
  • Click Inspect Profile to examine previous warning history.
  • Click Ban Offender to ban the reported user, or click Dismiss Report if the report is invalid.

💎 3. Monetization: Diamond Coin Packages

Important Note for Buyers: You are fully responsible for any transaction fees, processing rates, or service costs associated with third-party payment gateways (such as Google Play Billing, Apple In-App Purchases, Stripe, or PayPal) and cloud infrastructure usage (such as Firebase costs or VPS hosting). VibeMatch software does not cover these third-party operating expenses.

VibeMatch uses a diamond coin economy where users spend diamonds on animated gifts and VIP filters.

Navigate to Admin > Settings > Coin Packages to manage packages:

Figure 3: In-app diamond coin packages as rendered to users on Android and iOS.
  • Adding a Package: Click Add Coin Package. Enter the Package Name (e.g., "Popular Diamond Chest"), Diamond Count (e.g. 500), Bonus Diamonds (e.g. 50), and Price in USD (e.g. 4.99).
  • Setting Store Product ID: For mobile in-app purchases, set the Google Product ID and Apple Product ID to match the in-app purchase identifier configured in Google Play Console and App Store Connect (e.g., diamonds_500).
  • Click Save Packages to immediately publish changes to mobile apps and the web store without recompiling.

⭐ 4. VIP Subscription Plans & Durations

Navigate to Admin > Settings > VIP Membership to manage subscription tiers:

  • Duration Options: Configure plans such as 7 Days (Weekly), 30 Days (Monthly), and 365 Days (Yearly).
  • Pricing Mode: Set whether VIP can be purchased via direct payment (Stripe/PayPal/IAP) or unlocked using in-app diamonds.
  • Exclusive Perks: VIP members unlock gender filter matchmaking (connecting only with female or male partners), region filter selection, and an exclusive glowing golden badge on their profile avatar.

💳 5. Connecting Payment Gateways

Navigate to Admin > Settings > Payments to input your gateway credentials:

Figure 4: Payment Gateways and System Configuration Center.
  • Stripe: Toggle Stripe to Enabled. Enter your Publishable Key (pk_live_...) and Secret Key (sk_live_...). Enter the Stripe Webhook signing secret.
  • PayPal: Toggle PayPal to Enabled. Choose Environment (Live or Sandbox). Enter your PayPal Client ID and PayPal Secret Key from developer.paypal.com.
  • Razorpay: Enter Key ID and Key Secret for instant checkout in supported regions.
  • Click Save Payment Settings. The checkout buttons will immediately appear in the mobile store bottom sheet.
